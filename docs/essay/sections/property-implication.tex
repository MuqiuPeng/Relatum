\section{Property Implication Analysis}
\label{sec:property}

\subsection{Mechanism}

Given a set of named properties and a closed fact set, the system computes the \emph{extension} of each property---the set of ground elements satisfying it---and checks pairwise inclusion:

\begin{itemize}
\item $\mathrm{ext}(P) \subseteq \mathrm{ext}(Q)$ with $\mathrm{ext}(P) \neq \varnothing$ $\Rightarrow$ $\mathit{implies\_observed}(P, Q)$
\item Bidirectional inclusion $\Rightarrow$ $\mathit{equivalent\_observed}(P, Q)$
\end{itemize}

These are \emph{observed} (inductive) relations: they hold on the current data but are not deductively proven. They are intentionally separated from deductive \texttt{implies} to prevent modus ponens from cascading incorrect universalizations.

\subsection{Algebraic Properties}

On each of the 10 axiom classes (Table~\ref{tab:axiom-classes}), we define four properties via universal (double-negation) detection:

\begin{itemize}
\item $\mathit{left\_id}(e)$: $\forall x.\; \mathit{op}(e, x, x)$
\item $\mathit{right\_id}(e)$: $\forall x.\; \mathit{op}(x, e, x)$
\item $\mathit{idempotent}(e)$: $\mathit{op}(e, e, e)$
\end{itemize}

For each class, one representative operation table is selected and the property implication analysis is run.

\subsection{Key Findings}

Three structural laws emerge from Table~\ref{tab:property-table}:

\begin{enumerate}
\item \textbf{Identity determines left--right equivalence.} The column ``left $\leftrightarrow$ right'' is $\leftrightarrow$ if and only if the axiom class contains \texttt{id}. Associativity, commutativity, and inverse are irrelevant.

\item \textbf{Inverse (or commutativity with identity) determines identity--idempotent equivalence.} The column ``left $\leftrightarrow$ idem'' is $\leftrightarrow$ if and only if the class contains \texttt{inv}, or both \texttt{comm} and \texttt{id}.

\item \textbf{Associativity is independent.} Adding or removing \texttt{assoc} does not change any equivalence column. Compare \texttt{id} vs.\ \texttt{assoc+id}, or \texttt{comm+id} vs.\ \texttt{assoc+comm+id}: same pattern.
\end{enumerate}

Finding (3) is particularly notable: associativity---the defining axiom of semigroups---has no effect on identity-related property equivalences. This is consistent with the algebraic fact that left and right identities coincide in any monoid (associative or not, as long as an identity exists), but the system discovers this without being told.

\subsection{Contrast: Magma without Right Identity}

On a non-associative magma where $e_0$ is a left identity but no right identity exists, the system correctly finds:

\begin{itemize}
\item $\mathit{has\_property\_1}(e_0, \mathit{left\_id})$: detected
\item $\mathit{has\_property\_1}(e_0, \mathit{right\_id})$: \textbf{not detected} (no element satisfies $\forall x.\; \mathit{op}(x, e, x)$)
\item $\mathit{equivalent\_observed}(\mathit{left\_id}, \mathit{right\_id})$: \textbf{false}
\end{itemize}

This confirms that the mechanism distinguishes groups from non-groups by the internal relationship between left and right identity---discovered, not assumed.
