\section{Limitations and Capability Boundaries}
\label{sec:limitations}

We document the system's limitations with the same precision as its capabilities.

\subsection{Existential vs.\ Universal Detection}

Property detection rules of the form $\mathit{op}(e, x, x) \vdash \mathit{has\_property}(e, P)$ are existential: they fire when \emph{any} witness $x$ exists. For properties requiring universal quantification (``for all $x$''), double-negation detection is needed (two strata of negation). Existential detection gives false positives on non-group structures where $\mathit{op}(e, x, x)$ holds for some but not all $x$.

\subsection{$\omega$-Rule Defense and Pure-Transfer Blocking}

The $\omega$-rule promotes saturated inductive chains to pattern facts. When a pattern fact $P(\_0)$ triggers a downstream rule $P(x) \vdash Q(x)$ (pure variable transfer), the conclusion $Q(\_0)$ may be incorrect. The defense blocks non-ground conclusions from pure-transfer rules. This is conservative: some correct pattern facts are blocked (e.g., $\mathit{nonneg}(\_0)$ from $\mathit{nat}(\_0)$).

\subsection{Backward Application Disabled}

Backward (apply) rules $\mathit{has\_property}(e, P) \vdash \mathit{formula}(e, \ldots)$ cause cascading pattern facts in algebraic contexts where the operation relation has rich structure. Currently, property detection is forward-only. Backward inference from properties to formulas is deferred until proper grounding guards are designed.

\subsection{Property Implication Is Inductive}

$\mathit{implies\_observed}(P, Q)$ is based on current data: $\mathrm{ext}(P) \subseteq \mathrm{ext}(Q)$ at the moment of observation. It is not a logical proof and could be invalidated by additional elements. It is intentionally separated from deductive \texttt{implies} to prevent modus ponens from propagating inductive conclusions.

\subsection{Resource-Dependent Equivalence Failure}

When derivation rules have different growth rates (e.g., pairing $O(n^2)$ vs.\ subset $O(n)$), a finite fact budget is exhausted before slower rules catch up. Definitionally true equivalences appear as non-equivalences. The temporal convergence diagnostic (varying the fact cap) can detect this, but cannot resolve it without increasing the budget or removing competing rules.

\subsection{Carrier Size}

All algebraic results are on 3-element carriers. Transfer to $\mathbb{Z}_4$ is verified (6/6 predictions correct), but systematic exploration at $n > 3$ is computationally expensive ($4^{16} \approx 4.3 \times 10^9$ operations at $n = 4$).

\subsection{Zorn's Lemma and Second-Order Reasoning}

The system can verify properties of specific finite posets (maximal element existence) and can construct proof artifacts (chains, termination witnesses). It cannot prove universal theorems about \emph{all} posets, which requires structural induction (second-order reasoning). Zorn's Lemma is a capability boundary marker, not a system target. Depth-bounded ``maximal'' elements are artifacts of the depth limit, not genuine mathematical maximality; proof by contradiction correctly distinguishes the two.
