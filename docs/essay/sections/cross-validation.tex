\label{sec:cross}

\subsection{Four Meta-Patterns}

Four structural meta-patterns are tested across all three domains (11 instances total):

\begin{enumerate}
\item \textbf{Definitional equivalence in saturated structures.} In each domain, there exists a structure class where distinct-sounding properties have identical extensions: left and right identity in groups, maximal and minimal in antichains, set membership and subset-of-empty in the powerset chain. All 3/3 confirmed.

\item \textbf{Equivalence breaks in weaker structures.} When the structural conditions are relaxed, the equivalence fails. In algebra, a magma has left identity but no right identity. In order theory, a chain has a unique maximum $\neq$ minimum. In set theory, adding pairing causes a resource-dependent divergence. All 3/3 confirmed (2 structural, 1 resource).

\item \textbf{Strict implications.} In each domain, at least one implication holds without its reverse: identity implies idempotent (but not vice versa on the \texttt{id} class), isolated implies maximal (but not vice versa on chains), and containing empty implies being a set (but not vice versa). All 3/3 confirmed.

\item \textbf{Degenerate full equivalence.} In each domain, the most constrained structure (group, antichain, powerset chain) collapses multiple properties into full equivalence. All 3/3 confirmed.
\end{enumerate}

\noindent Total: 11/11 pattern instances confirmed. No counterexample found.

\subsection{Structural vs.\ Resource Failure}

A methodologically important finding: not all equivalence failures are alike.

\begin{definition}
An equivalence failure is \emph{structural} if the property extensions differ at all resource levels. It is a \emph{resource failure} if the extensions differ due to derivation-rate competition under a finite fact budget, but the equivalence is definitionally true.
\end{definition}

\noindent \textbf{Diagnostic criterion.} Run the engine at multiple fact-cap levels ($C_1 < C_2 < C_3$). Compute the extension gap $\delta_i = |\mathrm{ext}(P)| - |\mathrm{ext}(Q)|$ at each level.

\begin{itemize}
\item Structural: $\delta_1 = \delta_2 = \delta_3$ (constant).
\item Resource: $\delta_i$ varies with $C_i$ (cap-dependent).
\end{itemize}

\noindent On the magma (structural failure), the gap between $|\mathrm{ext}(\mathit{left\_id})|$ and $|\mathrm{ext}(\mathit{right\_id})|$ is 1 at all cap levels (100, 200, 500). On ZFC with pairing (resource failure), the gap between $|\mathrm{ext}(\mathit{is\_set})|$ and $|\mathrm{ext}(\mathit{superset\_of\_empty})|$ varies: 67\%, 67\%, 75\%.

This makes the structural/resource distinction \emph{testable}, not just conceptual. The engine can automatically flag which non-equivalences are resource-dependent by running at multiple cap levels.

\subsection{Interpretation}

The cross-domain consistency is not engineered. No part of the system was designed with these specific findings in mind. The property implication mechanism was built for algebra and then applied unchanged to order theory and set theory. The four meta-patterns emerged from the data.

This suggests that the extension-inclusion mechanism captures a genuine structural invariant of mathematical reasoning: the relationship between property extensions reflects the underlying logical dependencies between the properties' definitions, regardless of the specific mathematical domain.
